# Architecture Decision Records

This directory is reserved for concise records of architecture decisions that change system boundaries or persistent contracts.

No architecture decision records are currently present.

Use [template.md](template.md) for a new record. Number records sequentially:

```text
0001-short-decision-title.md
```

An ADR should document a decision, not restate implementation reference material. Use one when changing areas such as database backends, collection isolation, chunk payload contracts, query routing, graph activation, provider interfaces, or API compatibility.
